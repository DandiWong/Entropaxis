# Entropaxis

> Turns entropy into taxis: a human-AI workspace that routes disorder into structured, executable action.

---

## 🧑 人类须知

### 你是否期望你的电脑做到：

打开任意 AI 工具，说一句“调研商标申请规范并落盘为 word”，它就知道：

1. 联网检索资料。
2. 在你本地D盘的“知识产权/商标/”目录下创建“20260911_商标申请规范”子目录。
3. 把生成的“商标申请规范.docx”文件放到这个目录下。
4. 用本机安装的 Word/WPS 把这个 word 文档打开给你看。

这套系统就是这么用的。

### 当前支持场景示例（可自由扩展）

1. “起个事务 XX项目改版”，就会先去项目目录下找有没有同名的在办事项，有就直接告诉你路径，没有才新建一个日期+主题命名的文件夹，不会给你建出两个装同一件事的目录。
2. “报销归总”，就会把你从上次归总至今攒的发票自动核对金额、去重，生成一份报销清单并直接打开给你看。
3. “这条记下来”，就会把刚才这次判断的来龙去脉按标准格式追加进案例库，不会重写或删掉你之前记的条目。
4. “做审修回环”，就会先切成挑刺的审计角色，把你这版方案的问题按 Critical/Major/Minor 分级列出来；再切回方案角色逐条表态——认的直接改进原方案，不认的摆理由，不会另存一份 v2.md 出来。这么来回最多 3 轮，同一个问题卡住 2 轮就转给你拍板，不会自己无限兜圈子。
5. “开新迭代”，就会先检查当前分支干不干净、测试和 Lint 是不是全绿，不达标直接卡住不让继续；达标了才会补 Changelog、把完成的任务标记掉、原子提交，合回主干，再从干净的主干切出一个新分支开始下一轮，不会让你带着没收尾的活儿往前冲。

### Windows 安装

#### 推荐：使用 Agent 安装

把这句话贴给 AI Agent 工具：

“安装 https://github.com/DandiWong/Entropaxis 到当前选中的工作区目录并初始化”

> 安装目标是你在对话框/文件选择器中选中的那个工作区目录（而非 AI 工具的会话目录）。

#### 备选：使用 exe 安装包手动安装

从仓库 Releases 侧边栏下载一份 **`EntropaxisSetup.exe`**，双击即可：弹框选安装目录 → 展开控制面 → 自动初始化。控制面整份打在 exe 里，**安装全程不联网、不拉远端、不需要 GitHub 账号，也不需要先装 Python**。

装完日常使用仍需本机装有 Python 3（工作区的工具都是 `.py`）：到 <https://www.python.org/downloads/> 安装，记得勾选 **Add python.exe to PATH**。

### 引导与初始化契约

当 AI Agent 接入或初始化本工作区时，请严格遵守以下操作协议：

0. **工作区根目录判定（动手前先判定，装错即全错）**  
   安装目标 = **用户当前选中的工作区目录**，按以下优先级判定，命中即停，不得继续向下猜：
   1. **用户显式指定的路径/目录**：用户原话给出的绝对路径或目录名，无条件以此为准；
   2. **用户当前会话中选中/打开的工作区**：对话框文件选择器选中的文件夹、IDE 打开的项目根、终端当前目录（`pwd`）；
   3. **宿主注入的工作目录**：环境注入的项目/工作目录——使用前必须通过下一条「真伪校验」。
   **真伪校验（防装到非工作区）**：目标路径命中任一特征即为「非用户工作区」，必须停下来向用户确认目标目录，严禁静默安装：
   - Agent 自身沙箱/会话目录（如 `.sessions/`、`agents/<ID>`、Agent 工作区暂存目录）；
   - 宿主工具的会话/聊天目录（形如 `chats/<日期>/<会话名>`、会话 ID 目录）；
   - 临时目录（`/tmp`、`%TEMP%` 等）；
   - 系统/配置目录（`.config`、`Library`、`AppData` 等）。
   安装完成后验证：`.entropaxis/` 与同步出的根 `AGENTS.md`/`CLAUDE.md` 必须落在用户能看到、能打开文件的工作区根目录，用 `ls` 回读确认；判定不了就向用户要路径，不许猜。
1. **仓库挂载与初始化**  
   将本仓库作为 `.entropaxis/` 目录置于工作区根目录下，并首先执行入口配置同步工具：
   ```bash
   python3 .entropaxis/tools/bootstrap.py
   ```
   该工具会自动将 `.entropaxis/entrypoints/` 下的 `AGENTS.md` 与 `CLAUDE.md` 物理同步至工作区根目录，建立全局统一的规则控制面（纯文件复制，杜绝云同步网盘跨平台软链冲突）。
2. **规则与上下文纪律**  
   - 严格遵循根 `AGENTS.md` 常驻层控制面与 `.entropaxis/rules/` 架构规范；
   - 坚持**单一真源（Single Source of Truth）**、**上下文瘦身**与 **YAGNI 原则**，禁止跨层级复制规则或创建冗余文件；
   - 涉及多端任务与项目识别时，以 `.entropaxis/data/templates/registry.md` 实例注册表为唯一映射基准。

### 规则真源导航

总路由见根 `AGENTS.md`；本目录职责划分见 [`AGENTS.md`](AGENTS.md)；修改系统规则前必读 [`rules/00_元规则.md`](rules/00_元规则.md) 与 [`rules/01_根系统治理.md`](rules/01_根系统治理.md)（自迭代 SOP 与双重体检门禁）。业务项目实现细节沉淀于项目自身 README、Spec 或产物中，不反向污染系统抽象层。
