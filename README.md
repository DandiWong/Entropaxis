# 个人工作系统

一套由 Agent 和文件驱动的独立工作系统。系统工程只保存规则、模板和初始化工具；业务材料保存在同级项目目录中。

## 核心结构

```text
项目名/
├── AGENTS.md
├── _项目总览.md
├── _契约/
│   └── 当前状态.md
├── _知识库/
│   ├── index.md
│   └── 项目资料/
└── YYYYMMDD_事件名/
```

- `_项目总览.md`：项目入口、人员、时间线和最新产物索引。
- `_契约/当前状态.md`：当前有效的范围、结论、基线、风险和下一步。
- `_知识库/`：项目独有资料独立归档；共享资料只记录上层路径。
- `YYYYMMDD_事件名/`：按实际工作事件保存原始材料、工作稿和定稿。

## 日常循环

1. 开始工作前读取项目总览、当前状态和知识索引。
2. 在本次 `YYYYMMDD_事件名/` 中处理材料并保存产物。
3. 结束后更新项目总览的时间线和最新产物。
4. 只把本次已经确认的变化写入当前状态。
5. 对外发布前按 `rules/对外发布规则.md` 取得人工确认。

时间线回答“事情怎样发生”，当前状态回答“现在以什么为准”，项目总览回答“从哪里开始看”。

## 初始化项目

优先让 Agent 使用 `skills/init-project`。底层命令：

```bash
python3 tools/init_project.py "项目名" \
  --purpose-goal "用途和目标" \
  --people "负责人及相关人员" \
  --next-event "下一关键事件" \
  --materials "已有材料位置" \
  --project-knowledge "项目独有知识" \
  --shared-knowledge "共享知识路径" \
  --sensitivity "敏感级别"
```

默认在 `00_系统工程` 同级创建项目。目标已存在时拒绝覆盖。

## 设计边界

不建设节点图、工作流状态机、契约注册表、Skill 接线表、RBAC 或协作平台。需求摘要、评测报告、PRD、计划和汇报仍可使用专业 Skill 生成，但它们是项目产物，不是系统运行所必需的接口。
