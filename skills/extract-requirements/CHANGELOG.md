# Changelog

All notable changes to the `extract-requirements` skill will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-11

### Added
- 初始版本发布：将需求提炼与分析从一体化流程中独立解耦为专项指令。
- 确立需求提炼四步法：真源溯源穿透、场景全景图（虚线框介入）、干系人诉求矩阵化、过度设计诊断。
- 引入断点机制：止于需求清单与裁剪清单落盘，为用户留出独立检查确认窗口。
