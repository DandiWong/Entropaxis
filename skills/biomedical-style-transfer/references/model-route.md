# GPT Image 2.5 本机订阅路径

## 型号

用户指定 GPT Image 2.5 系列。本技能默认使用 `gpt-image-2.5-sunburst`，因为官方将其定位于重视编辑精度的场景；另有 `gpt-image-2.5-flare`，不得自动切换。

依据：[GPT Image 2.5 Sunburst 官方模型说明](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)。该页面证明模型身份与能力，不证明某个订阅账号或 Codex 版本可以调用它；API 的模型参数不能直接套入 Codex CLI。

## 调用契约

- 使用本机 Codex 的 ChatGPT 登录；不使用单独 API Key 或 API 计费通道。
- `codex exec -m` 选择 Agent 模型，不等同于为原生图像工具选择图像模型。
- 原生图像工具必须有可验证的 2.5 模型选择入口，或可信工具契约给出的固定型号映射。没有二者之一时先停止，不靠提示词或图像外观宣称已使用指定模型。
- 选择参数只能在当前 CLI / 工具文档或实际工具 schema 中核实后使用；不猜测 `image_model` 等配置键。Codex 可接受配置覆盖语法，不代表任意键都会生效。
- 官方模型页、登录成功和生成成功均不能单独证明实际模型。保留本次调用的选择或映射依据；若返回执行型号，进一步核对。
- 模型能力不可用时保留内容清单和提示词，报告阻断原因；不要求用户重新确认已选路径，也不自动改用其他服务。
