# 发票归总执行套件 (Invoice Collector)

判据、账目完整性红线与交付契约的唯一真源是 [`../../rules/财务报销.md`](../../rules/财务报销.md)；企业与环境参数唯一真源是 `.data/rules/reimbursement-config.md`。本 Skill 只承载「已决定执行归总之后」的操作细节，不重复判据。

---

## 1. 目录结构

```
<ReimbursementRoot>/
├── YYYY-MM-DD/                          # 当日归总目录（按发票业务类型分目录）
│   ├── 交通/                             # 日常市内交通（通勤燃油、市内打车、地铁公交、日常停车通行）
│   ├── 差旅/                             # 出差差旅专项（以酒店住宿发票时间建立目录，如 YYYY-MM-DD 或 YYYYMMDD-YYYYMMDD_{事由}）
│   │   ├── YYYY-MM-DD/                  # 单次出差专包（以酒店住宿发票时间建立目录）
│   │   │   ├── 酒店住宿发票及水单
│   │   │   ├── 机票 / 火车票 / 跨城客运发票及行程单
│   │   │   ├── 出差地当地网约车 / 出租车 / 燃油等差旅交通发票及行程单
│   │   │   └── 境外差旅外币汇率牌价截图（若涉及）
│   │   └── ...                          # 其他出差行程专包
│   ├── 通讯/                             # 手机话费充值、宽带网络、通讯运营商月结发票
│   ├── IT/                               # IT 与数字化服务：Apple、Cloudflare、Claude、OpenAI、AWS、模型 API、云算力平台、云基础设施付费
│   ├── 餐饮/                             # 商务宴请、业务招待、日常外卖等餐饮服务发票
│   ├── 办公/                             # 办公耗材、文具用品、图书资料、软件许可、设备配件等
│   ├── 团建/                             # 团队建设活动、聚餐、团建场地租赁、文体拓展等专项
│   ├── 待处理/                           # 无法自动获取/解析的票据暂存，原文件名保留
│   ├── 其他/                             # 快递物流、公证认证等未单独列出的零星支出发票
│   └── 清单.md                           # 当日归总台账
└── Archive/                              # 历史已报销归档目录（只读锁定）
    └── YYYY-MM-DD/                       # 报销流程审批或提报完成后整体移入
```

用户手动放入 `<ReimbursementRoot>` 根目录的发票，在下一次归总时自动识别、重命名并移入当天的分类子目录。

## 2. 配置缺失时的交互补填

配置前置门禁的判据见规则第 1 节。执行侧动作：

1. `.data/rules/reimbursement-config.md` 不存在时，先创建含必填字段列表的空白配置。
2. 必填字段：`<ReimbursementRoot>` 绑定、至少一个企业主体（抬头 + 统一社会信用代码，支持多主体）、合规阈值（超期天数、汇率源）、政策真源。
3. 缺失项从配置文件「候选检索来源」所列位置检索候选值，逐项列出「缺失字段 + 候选值 + 来源」请用户确认或补填。
4. 用户确认后回写配置；当场无法提供时保留缺失标记，相关校验在 `清单.md` 按「无法校验」预警，并当次告知影响。

## 3. 提取与转换

1. **格式标准**：核心凭证仅收录 PDF 与清晰发票图片（PNG / JPG / JPEG / HEIC）。排除 XML、OFD（除非财务特别要求）、系统签名文件、纯说明性文本。
2. **纯 HTML 账单与收据**：邮件中无 PDF 附件但含完整结算金额与明细的电子收据，渲染为标准 A4 尺寸 PDF 后归集。
3. **辅助行程单**：网约车行程报销单、航班行程单、酒店水单等添加 `_行程单` 后缀存入对应分类目录，在 `清单.md` 中单独标注。

## 4. 分类映射

| 类别 | 范围与关键词特征 |
|---|---|
| **交通** | 日常市内交通：市内加油、日常市内打车/客运服务费、市内公共交通、日常停车通行费 |
| **差旅** | 出差全流程专包：异地酒店客房/住宿、机票、火车票、出差期间异地用车及燃油（见第 5 节） |
| **通讯** | 电信服务、信息技术服务话费、移动通信费、宽带月结账单 |
| **IT** | IT 与数字化服务：Apple、Cloudflare、Claude、OpenAI、AWS 等订阅工具、模型推理与 API 调用、GPU/云算力、云基础设施付费 |
| **餐饮** | 餐饮服务、生产生活服务餐饮、日常就餐、外卖餐饮、商务招待 |
| **办公** | 办公耗材、电脑外设配件、文具纸张、图书资料、办公软件授权、快递邮寄 |
| **团建** | 团队建设费、团队文体活动、团建拓展聚餐、团建场地租赁 |
| **其他** | 会议注册费、培训费、规费、其他未明确分类项目 |

## 5. 差旅行程专包

日常交通与出差交通报销流程及标准不同，出差凭证必须按次归集到独立行程专包。

1. **命名**：以出差住宿酒店发票的开票/入住日期建立目录，命名形如 `差旅/YYYY-MM-DD/`（或附带事由 `差旅/YYYY-MM-DD_{出差事由}/`）。
2. **归口原则**：差旅专包按酒店发票的记录日期归入对应日期的分类目录（例如住宿发票记录时间为 2026-06-26，则归入对应归总批次下的 `差旅/2026-06-26/` 目录）。
3. **收录原则（时间 + 地点联动）**：
   - 住宿凭据：出差期间的酒店住宿发票及水单；
   - 大交通凭据：往返出差城市的飞机票、铁路客票、城际客运发票及行程单；
   - 出差地交通：在出差起止日期范围内、发生在出差当地的网约车、出租车、加油费等发票，统一收拢到该专包，不得混入日常 `交通/`。

## 6. 外币与汇率折算

1. **牌价截图留存**：获取该笔消费当日（开票日）配置汇率源对应机构的官方牌价页面截图，保存至该 Invoice 所在分类目录，命名 `YYYYMMDD_汇率牌价_{币种}_{牌价机构}.png`。
2. **汇率选用基准**：汇率源及回退链（折算价 → 现汇买入价 → 外汇交易中心中间价）以配置文件合规阈值为准。
3. **换算公式**：

   $$\text{报销人民币金额 (元)} = \text{外币金额} \times \left(\frac{\text{折算价}}{\text{牌价公布单位}}\right)$$

   牌价公布单位以配置汇率源的公布口径为准（如折算价为每 100 外币兑人民币，则单位为 100）。

## 7. 合规风控执行动作

1. **抬头与税号校验**：核对购买方名称及统一社会信用代码是否匹配配置文件企业主体清单中的任一主体（报销可能涉及集团/子公司多主体）。均不匹配时文件名追加 `_待核抬头`，在 `清单.md` 标红 `⚠️ [待核实抬头]`。
2. **专票/普票税额拆解**：提取增值税税率、税额与不含税金额，在 `清单.md` 单独列明「发票类型（数电专票/数电普票/行程单）」及「税额」，便于财务系统录入进项税抵扣。
3. **红字冲减发票**：识别负数发票与冲红记录，文件名追加 `_红字冲减`，在汇总面板与明细中单独体现抵减项。
4. **辅助支付凭据**：大额餐饮宴请、办公采购附带的付款截图、POS 小票或消费清单，命名 `YYYYMMDD_发票号码_支付凭据.png` / `YYYYMMDD_发票号码_消费明细.pdf`，与对应发票同目录存放并在清单标注关联。
5. **开票超期与跨年**：核验开票日期，超过配置文件超期阈值或跨会计年度的发票，在 `清单.md` 标注 `⚠️ [发票超期预警]`，提示优先报销或走特殊审批。

## 8. 异常降级操作

无法自动完成获取或解析的票据不阻塞归总任务：

- **适用情形**：短信开票链接失效/过期、汇率牌价页面不可访问、发票图片模糊无法可靠 OCR、境外 Invoice 缺失可解析 Invoice ID 等。
- **降级动作**：原文件（或线索截图）保留原文件名移入当日 `待处理/`；无文件仅有线索的，在 `清单.md` 记录线索来源。
- **台账呈现**：异常与合规预警面板单列 `⚠️ [待处理]`，注明失败环节（获取/解析/汇率/OCR），待人工补齐后随下一次归总重新归集。

## 9. 文件命名

| 类型 | 格式 |
|---|---|
| 国内数电/电子发票 | `YYYYMMDD_发票号码_金额元_销方简称.pdf` |
| 国际 / 境外 Invoice | `YYYYMMDD_InvoiceID_金额币种_服务商.pdf` |
| 汇率牌价凭据 | `YYYYMMDD_汇率牌价_币种_牌价机构.png` |
| 行程单与辅助凭证 | `YYYYMMDD_发票号码_平台名称_行程单.pdf` |
| 支付凭据 / 消费明细 | `YYYYMMDD_发票号码_支付凭据.png` / `YYYYMMDD_发票号码_消费明细.pdf` |
| 红字冲减发票 | `YYYYMMDD_发票号码_负金额元_销方简称_红字冲减.pdf` |

## 10. `清单.md` 台账结构

- **汇总面板**：
  - 发票总张数（专票 / 普票 / 境外 Invoice 分列）；
  - 各分类小计（含差旅各行程专包小计）；
  - 国内发票合计（价税合计、不含税金额、税额）；
  - 境外外币发票原币合计及按配置汇率源折算后的人民币金额；
  - **最终报销总折合人民币金额** = 国内发票价税合计 + 外币折算人民币金额 − 红字冲减金额；
  - **异常与合规预警面板**（超期发票、待核抬头发票清单、待处理条目）。
- **发票明细清单**：序号、开票日期、类别（注明所属差旅专包）、发票号码/ID、发票类型、开票方/服务商、原币金额、折算价、报销人民币金额、税额、汇率/关联凭证、文件名、合规状态。
- **辅助凭证清单**：行程单、支付凭据等辅助凭据及其对应发票与文件。

## 11. 交付前自检

1. 提取的 PDF / 图片 100% 可正常打开与解析；
2. 发票号码、原币金额、税额与票面信息完全一致；
3. 外币 Invoice 均已配齐对应牌价截图，且折算金额计算无误；
4. 日常交通与差旅专包边界清晰，无混放与重复文件；
5. 完成打开闭环并核对逐项执行结果：工作区提供 `.system/tools/open_file.py` 时调用它打开 `清单.md`（判据见《文件交付》第 4 节），不存在时回报其绝对路径由用户自行打开。不得自建第二份打开实现。
