# Changelog

## 1.1.0

- 对根系统零依赖（《技能设计》6.2 独立运行铁律）：打开闭环改为「工作区提供 `.system/tools/open_file.py` 则调用，否则回报绝对路径」，不再硬依赖 `.system/`；自身脚本路径改为相对 `<skill-dir>` 定位，脱离工作区独立安装亦可运行。

本文件记录 `invoice-collector` Skill 的所有显著变更，遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 规范，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [1.1.0] - 2026-09-08

### Changed
- 分类目录调整：将原 `AI/` 类目更名为 `IT/`，统一承载 Apple、Cloudflare、Claude、OpenAI、AWS 等数字化订阅、模型 API 与云基础设施开支。
- 差旅专包归档规则优化：明确差旅专包以酒店住宿发票的记录日期建立目录并归入对应日期的类目中（如 `差旅/YYYY-MM-DD/`）。

## [1.0.0] - 2026-09-04

### Added
- 首次发布。从 `.system/rules/财务报销.md` 下沉全部执行细节：目录结构、配置交互补填、提取与转换、分类映射、差旅行程专包、外币汇率折算、合规风控执行动作、异常降级、文件命名、台账结构与交付前自检。
- 示例中的机构与事由名称统一替换为泛化代称，符合《01_根系统治理》铁律 6 零真实实体要求。

### Changed

- 判据、账目完整性红线与交付契约保留在规则真源《财务报销》，本 Skill 不重复声明，遵循《01_根系统治理》「领域规则只做编排」准则。
