# Changelog

本文件记录 `invoice-collector` Skill 的所有显著变更，遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 规范，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [2.1.1] - 2026-10-06

### Changed
- `清单.md` 生成后不再自动打开，只回报绝对路径（跟随《文件交付》第 4 节 `.md` 不自动打开）。

## [2.1.0] - 2026-09-29

### Changed
- 文件重命名规范重构：统一依据提取的核心信息重命名为 `{起止日期}_{平台}_{发生地}_{金额}.ext`。跨日行程/消费按 `YYYYMMDD-YYYYMMDD`（如 `20260623-20260626_滴滴_北京_177.2元.pdf`），单日消费省略截止日（如 `20260625_高德_上海_45.0元.pdf`）；辅助凭证与行程单同步继承该格式并保留类型后缀。

## [2.0.0] - 2026-09-27

### Changed
- 收集范围、增量 Baseline、账目完整性红线与归档流转从控制面规则《财务报销》并入本 Skill（第 0 节），本 Skill 成为报销判据唯一真源，脱离工作区独立运行不再丢失红线；控制面规则《财务报销》退役。

## [1.3.0] - 2026-09-26

### Changed
- 企业与环境参数从控制面实例数据目录收回到 Skill 自身目录 `config.md`（`.gitignore` 排除），Skill 不再读写控制面 `data/`（《技能设计》2.2）。

## [1.2.0] - 2026-09-13

### Added
- 排重终态契约：两级排重命中的重复票据保留原文件名移入当日 `重复跳过/` 目录，不再遗落 `<ReimbursementRoot>` 根目录反复触发排重；台账预警面板单列 `⚠️ [重复跳过]` 注明命中比对键与既有文件位置；文件不删除，处置由用户仲裁。判据同步补入规则真源《财务报销》红线 5。

## [1.1.0] - 2026-09-08

### Changed
- 对根系统零依赖（《技能设计》2.2 独立运行铁律）：打开闭环改为「工作区提供 `.entropaxis/tools/open_file.py` 则调用，否则回报绝对路径」；自身脚本路径改为相对 `<skill-dir>` 定位。
- 分类目录调整：将原 `AI/` 类目更名为 `IT/`，统一承载 Apple、Cloudflare、Claude、OpenAI、AWS 等数字化订阅、模型 API 与云基础设施开支。
- 差旅专包归档规则优化：明确差旅专包以酒店住宿发票的记录日期建立目录并归入对应日期的类目中（如 `差旅/YYYY-MM-DD/`）。

## [1.0.0] - 2026-09-04

### Added
- 首次发布。从控制面规则《财务报销》（已于 2.0.0 退役）下沉全部执行细节：目录结构、配置交互补填、提取与转换、分类映射、差旅行程专包、外币汇率折算、合规风控执行动作、异常降级、文件命名、台账结构与交付前自检。
- 示例中的机构与事由名称统一替换为泛化代称，符合《01_根系统治理》铁律 6 零真实实体要求。

### Changed

- 判据、账目完整性红线与交付契约保留在规则真源《财务报销》，本 Skill 不重复声明，遵循《01_根系统治理》「领域规则只做编排」准则。
