# Req to Demo — 需求到高保真交互 Demo 实践

本 Skill 编排从会议转写与业务材料提取真实需求、场景建模、过度设计裁剪，到最终出具高保真单文件 HTML 交互 Demo 的全流程最佳实践。

规范细节见 [`references/ipo-demo-spec.md`](references/ipo-demo-spec.md)；脚手架工具见 `scaffold_demo.py`。

## 进度清单

复制到对话逐项打勾：

- [ ] 1 溯源穿透取真源（检索会议录音转写、既有材料包与历史脱敏资产，落盘存证）
- [ ] 2 场景全景画虚线（梳理端到端业务流，用【虚线框】标明智能体赋能介入边界）
- [ ] 3 减负裁剪去过度（对标客户客体现状与 GCP/业务规范，剔除 4 类过度设计）
- [ ] 4 IPO 流水线脚手架（生成或实例化单文件 HTML，锁定阶段与三栏联动）
- [ ] 5 极致交互免说明书（配置空态占位、Mock点击切换、宽屏呼吸感与通俗人话文案）
- [ ] 6 交付验证与打开闭环（通过 `scaffold_demo.py --lint` 体检，调用 `open_file.py --on-deliver` 确认）

## 核心流程五步法

### 1 溯源穿透取真源（不凭空编造）
1. **调取会议转写**：使用腾讯会议 CLI（`tmeet`）调取专项会议记录，抓取官方智能纪要与原始逐字稿，存入 `腾讯会议历史_<主题>/`。
2. **穿透解析回执材料**：用 Python 脚本解析客户回执的 Excel 需求草案、Word 专利表单及脱敏表单 PDF。
3. **沉淀事实底册**：将分散素材沉淀为 `01_需求清单.md`（按 `REQ-{{yyyymmdd}}-NN` 继承编号）与 `hospital_reqs.json`。

### 2 场景全景画虚线（不争抢成熟系统既有功能）
1. **解构客体现状**：严格区分甲乙双方或不同业务主体环境（如药企注册 vs 医院临床科研；内网既有商业系统现状）。
2. **绘制全景图**：画出从业务源头到结束的全流程全景图。
3. **标注介入切点**：在全景图中使用**【虚线框】**精确框定产品赋能范围，一眼明晰“只在建库前期的规则生成与质检环节发力，不取代既有系统的成熟运行环节”。

### 3 减负裁剪去过度（坚守 MVP 最小可行实现）
对照业务事实底册，坚决排查并裁剪以下 4 类过度设计：
- 🔴 **重复造轮子**：既有系统已有成熟功能的录入端、审核流与复杂表单，绝不自建一套假冒伪劣版本；
- 🔴 **极客黑框终端**：终端黑框命令行（Terminal）严重增加非技术人员认知负荷，一律剔除并改为业务步骤卡片；
- 🔴 **学术化强制认证**：非专职团队场景下，不生搬硬套大而全的标准规范（如强制 CDASH 域代码映射），优先解决强标准化问题；
- 🔴 **未授权动态反哺**：规范合规严禁程序动态改写生产规则，一期坚决拿掉动态反哺概念，强调专家审核基线锁定。

### 4 IPO 流水线脚手架（步进联动）
1. **骨架生成**：调用 `python3 .entropaxis/tools/scaffold_demo.py --title "<项目>交互Demo" --stages "阶段1,阶段2,阶段3,阶段4" --out <path.html>`。
2. **结构规范**：
   - **顶部 Stepper**：显式步进导航，初始仅阶段 1 激活，后续阶段置灰锁定（`locked`）；
   - **IPO 三栏栅格**：严格采用 `grid-template-columns: 280px minmax(340px, 1fr) 630px;`（左 Input、中 Process、右 Output）；
   - **流水线继承**：完成上阶段后，自动解锁下阶段，下阶段 Input 显式展示绿色继承提示框（`✔ 已继承上一阶段产出成果...`）。

### 5 极致交互免说明书（用控件呈现价值）
1. **初始空态占位（Empty State）**：中栏与右栏初始呈现干净的空态卡片，杜绝首屏杂乱数据。
2. **点击 Mock 就绪（演示利器）**：输入端放置虚线卡片，用户轻点即刻切换为带绿对勾的“脱敏样本已就绪”状态。
3. **文案讲一线人话**：
   - 拒绝晦涩术语（如将“触发自动下发的 Query 提示语”改写为“录入报错提示语（数据录错时，弹给医生看的话）”）；
   - 逻辑表达式采用等宽字体与深灰背景，报错提示采用暖黄气泡卡片，形成视觉对比。
4. **版本保护铁律**：激进重构原型前，必须就地备份稳定底稿（如 `index.backup_YYYYMMDD.html`），支持随时安全回滚。

### 6 门禁体检与交付
1. **自动化规范体检**：执行 `python3 .entropaxis/tools/scaffold_demo.py --lint <demo.html>`，确保阻断项清零。
2. **物理打开闭环**：执行 `python3 .entropaxis/tools/open_file.py --on-deliver <demo.html>` 唤起浏览器，请用户确认效果。
