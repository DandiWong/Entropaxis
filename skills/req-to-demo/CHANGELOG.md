## [1.0.0] - 2026-11-11

### Added
- 初始版本发布：固化从业务会议/原始材料提取需求到出具单文件 HTML 交互 Demo 的全流程最佳实践。
- 确立 S-Tier 推进链路五步法：溯源穿透、场景全景（虚线介入）、过度设计裁剪、IPO 流水线脚手架、免说明书式交互。
- 制定 IPO 三栏栅格规范、630px 宽屏 Output 呼吸感排版、暖黄人话气泡卡片与点击 Mock 切换就绪标准。
- 配套提供 `scaffold_demo.py` 工具与单测套件，支持骨架原子生成与 `--lint` 门禁体检。
