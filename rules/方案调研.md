# 方案调研

适用于跨领域（技术选型、前沿探索、临床医学、业务竞品、管理流程等）的事实调研与方案比选。只回答一个事实问题、不需要比选时不适用，按普通问答处理。触发与落盘见 [`工作流指令.md`](工作流指令.md)「调研 / 方案调研」。

## 一、三条硬门禁

1. **证据第一**：涉及前沿方案、库表选型、行业数据、法规政策时，必须联网检索或查阅权威知识库，不得仅凭模型记忆输出；关键论点、基准与参数标注一手信源，格式 `[信源名称/文档标题/年份/链接]`。
2. **多方案对比**：横向对比 2~3 个主流路线、学术流派或行业标杆，写明各自优劣与适用边界，不得只论证单一方案。
3. **确定性边界**：分别列出已知事实、未知/待验证事项与前置假设，事实与推断分开写。

## 二、六个评估维度

1. **证据等级**：采用一手权威出处（官网、顶级论文、监管批件、财报）；淘汰自媒体二手文章与营销软文。
2. **时效性**：反映近 3~12 个月的演进与行业共识；淘汰已停止维护或已被替代的方案。
3. **合规红线**：符合适用法域法规、行业许可、数据安全与开源协议（NMPA/FDA/GDPR 等）；淘汰无法合规立项的方案。
4. **工程可行性**：低侵入、低迁移与维护成本，有可落地步骤；淘汰过度设计。
5. **生产可靠性**：经过规模化生产检验或有量化基准；淘汰停留在 Demo、边界条件脆弱的方案。
6. **风险收益**：估算试错与实施成本、最坏情况、止损点与备选方案。

## 三、场景偏好与信源

- **医药/生物/临床科研**：最高循证等级、临床分期明确 · PubMed、NMPA/FDA 批文、Cochrane、ClinicalTrials
- **行业市场/竞品**：一手财报、真实商业闭环、单位经济模型 · 上市公司年报、行业研报、专利局
- **前沿科学/概念梳理**：源头论文与演进脉络 · arXiv、Nature/Science、学会综述
- **运营/管理/流程**：标杆对标、分工与防呆机制 · 标杆企业公开案例、ISO/精益体系、行业标准
- **AI/Agent 架构**：近 3~6 个月前沿、权威基准、官方最佳实践 · 顶会论文、头部实验室官方文档、开源实现
- **软件工程与技术选型**：生态共识、低侵入、社区活跃、商业友好协议 · 官方仓库、RFC、官方文档
- **监管法规/合规/专利**：现行有效、法域精确、穿透到细则与豁免 · 监管机构官网、专利数据库、指导原则
- **供应商/SaaS 采购**：全生命周期 TCO、私有化与数据主权、SLA · 公开定价、用户评价、技术支持文档
- **数据资产/标准词表**：对齐权威标准、授权清晰 · ICD/SNOMED/MeSH、官方认证数据集
- **疑难故障/根因**：底层机理、最小破坏性修复、源码级佐证 · 官方 Issue Tracker、变更日志、源码

## 四、交付物结构

调研产出（对话内呈现或落盘为 `01_调研.md`）采用四段式：

1. **执行摘要**：结论先行，一分钟看懂推荐方案与关键取舍；
2. **多方案对比**：2~3 个候选按第二节六个维度逐项对比，定性结论附依据，定量数据附信源，不给无依据的打分；
3. **主推方案与落地路径**：里程碑、输入输出、边界条件与关键操作；
4. **风险与备选**：合规、技术、成本风险与替代路线。
