# 工作区自然语言指令

当用户以“同步”“同步任务”“任务”“记录/沉淀”或“复盘”明确发起操作时，按本文件解释意图。普通问答或提到这些词不自动触发写入。

所有外部写入仍受根 `AGENTS.md` 安全边界约束。精确命令以对应工具和专项规则为准，本文件不复制 CLI 参数。

## 同步

用于核对项目本地状态、Board-Platform 与 Dashboard。

1. 按 `项目运行规则.md` 定位项目，按稳定任务 ID 和 `source_ref` 配对。
2. 读取各端状态与可用时间证据，先列差异。
3. 修改时间只能辅助判断，不能单独决定语义真源；发生冲突时优先采用项目声明的本地状态真源，无法判断则报告待确认。
4. 经授权后按 `开发项目联动规则.md` 幂等更新，并回读验证。
5. 删除、关闭、覆盖或无法回滚的差异不自动处理。

## 同步任务

用于把已经人工确认的会议或事件行动项写入 Dashboard。

- 先定位来源文件并提取项目、负责人、截止日期、内容和稳定 `source_ref`。
- 未经人工确认的会议纪要行动项只保留为草稿。
- 写入方式与回读检查见 `internal-board` Skill §6（source_ref 与准入标准）。
- 输出逐项成功、失败与缺失字段，不用汇总成功掩盖部分失败。

## 任务

用于把用户明确要求登记的自然语言任务写入任务系统。

- 按 `项目运行规则.md` 解析项目、负责人、截止日期和可执行内容。
- 项目有 `docs/.board.json` 时按 `开发项目联动规则.md` 使用同一任务 ID；其他项目只写用户指定的系统。
- 不因纯问答、查找或建议自动建任务。
- 多个项目同样匹配或关键字段会改变归属时再询问。

## 记录 / 沉淀

按 `知识库规则.md` 判断目标形态：

- 离散事实或交付物：新文档。
- 持续演进的基线：更新既有真源。
- 长期行为约束：修改相应层级的规则。
- 高频、可复用且步骤稳定的流程：评估为 Skill。

先读取目标文件并保留现有内容。用户已经明确要求修改规则时，不重复索取同一授权；写入外部系统或扩大范围仍需单独授权。

## 复盘

用于回顾用户指定项目和时间范围，识别重复劳动、纠正、知识缺口、决策变化与未闭环事项。

- 默认产出分析和建议；只有用户明确要求落盘时才创建复盘文档。
- 规则建议进入相应规则真源，项目事实进入当前状态真源，行动项只有在“任务/同步任务”被明确触发时才写入外部系统。
- 证据不足的判断标为待确认，不补写不存在的历史。
